# Налаштування ноутбука бабусі (Windows + Chrome)

Інструкція для онука. Робиться один раз.

## 1. Встановити розширення
1. Скопіюйте теку з розширенням на ноутбук, наприклад у `C:\Babusia\GrannyExtention` (не видаляйте її потім — Chrome читає файли звідти).
2. Відкрийте в Chrome `chrome://extensions`.
3. Увімкніть **«Режим розробника»** (перемикач праворуч угорі).
4. Натисніть **«Завантажити розпаковане»** і оберіть теку з файлом `manifest.json`.
5. Відкрийте нову вкладку. Chrome запитає, чи залишити зміни нової вкладки — натисніть **«Залишити зміни»** (Keep changes). Якщо вікно зникло, його можна не побачити: головне, щоб нова вкладка показувала велику сторінку з годинником.
6. Chrome може показувати попередження про «розширення в режимі розробника» при запуску. Закрийте його; не натискайте «Вимкнути».

Після зміни файлів розширення натисніть на `chrome://extensions` кнопку оновлення біля розширення.

## 2. Автозапуск Chrome разом із Windows
1. Натисніть `Win + R`, введіть `shell:startup`, Enter.
2. У відкритій теці створіть ярлик Chrome (правою кнопкою → Створити → Ярлик → шлях `C:\Program Files\Google\Chrome\Application\chrome.exe`).
3. Бажано додати до ярлика (Властивості → Об'єкт) в кінці: ` --start-maximized`.
4. Також у налаштуваннях Chrome (Під час запуску) оберіть «Відкрити сторінку «Нова вкладка»».
5. Щоб ноутбук входив у Windows без пароля — `Win + R` → `netplwiz` (за бажанням).

Розклад працює, лише поки Chrome запущений. Не дозволяйте закривати Chrome: у Налаштуваннях Chrome → Система увімкніть «Продовжувати роботу фонових програм після закриття Chrome».

## 3. Щоб ноутбук не засинав
Параметри Windows → Система → Живлення (Живлення та батарея):
- «Екран і сон» → **Від мережі: Сон — Ніколи**; вимкнення екрана — за бажанням (наприклад 30 хвилин).
- Параметри кришки: «Закриття кришки» → від мережі «Нічого не робити».
- Залишайте ноутбук підключеним до зарядки.

## 4. Мікрофон для голосового пошуку
1. Відкрийте налаштування розширення (значок розширення на панелі Chrome або `chrome://extensions` → Відомості → Параметри розширення).
2. У розділі «Мікрофон» натисніть **«Дозволити мікрофон»** і у вікні Chrome оберіть «Дозволити».
3. Перевірте, що Windows дозволяє мікрофон: Параметри → Конфіденційність → Мікрофон → увімкнено для настільних програм.
4. Перевірте голосовий пошук на головній сторінці. Потрібен інтернет (розпізнавання робить Chrome).

## 5. Віддалена допомога (Chrome Remote Desktop)
1. На ноутбуці бабусі відкрийте `remotedesktop.google.com/access` у Chrome під вашим акаунтом Google.
2. «Налаштувати віддалений доступ» → встановіть, задайте назву і PIN.
3. З вашого пристрою відкрийте той самий сайт і підключайтеся для допомоги.

## 6. Налаштування розкладу
Відкрийте сторінку налаштувань розширення. Розділ «Розклад трансляцій» → «Додати запис».

| Поле | Що вводити |
|---|---|
| Назва для бабусі | Наприклад «Вервиця». Саме це вона побачить. |
| Тип джерела | **Канал YouTube** — шукати трансляцію за ключовими словами; **Відео YouTube** — одне постійне посилання (наприклад цілодобова трансляція `https://www.youtube.com/watch?v=Bcp9VNIW4ss`); **Профіль Facebook** — сторінка людини, наприклад `https://www.facebook.com/назва.профілю`. |
| Посилання | Адреса каналу (`https://www.youtube.com/@ugcctv`), відео або профілю. |
| Ключові слова | Лише для каналу. Частина назви трансляції, наприклад `ВЕРВИЦЯ ЄДНАЄ`. Регістр і зайві пробіли не важливі. Кілька варіантів — через `;`. |
| Дні тижня | Позначте дні або «щодня». |
| Час | Початок, `ГГ:ХХ`. |
| Попередити за | Хвилин до початку (за замовчуванням 3). |

### Як вибирається трансляція на каналі
Розширення читає сторінку `канал/streams` (не `/live`, бо вона ненадійна — на каналі може бути кілька ефірів одночасно):
1. Якщо є ефір **«НАЖИВО»**, назва якого містить ключові слова — відкривається він (якщо їх кілька, перевага тому, у назві якого сьогоднішня дата).
2. Інакше — запланована трансляція, у назві якої є **сьогоднішня дата** (формат `3.11.2026` або `03.11.2026`) і ключові слова.
3. Інакше розширення перевіряє щохвилини протягом 15 хвилин, показуючи «Трансляція ще не почалася, зачекайте…», потім «Сьогодні трансляції немає».

### «Перевірити зараз»
Біля запису каналу натисніть **«Перевірити зараз»** — побачите, яку трансляцію було б відкрито зараз (назву й стан) або «не знайдено». Підбирайте ключові слова так, щоб вони були у назві потрібних трансляцій і не збігалися з чужими.

### Що відбувається у час запуску
За N хвилин до початку відкривається велика сторінка «Скоро …» з кнопкою «Дивитися» (Enter) і «Не зараз», лунає звук. Якщо нічого не натиснути, у час початку трансляція відкриється сама. За бажанням у «Звук оголошення» завантажте або запишіть голосове повідомлення (інакше — дзвіночок).

## 7. Інше в налаштуваннях
- **Плитки на головній** — сайти, які бачить бабуся (значок, назва, адреса).
- **Теми** — фрази для пошуку (по одній на рядок; чим більше, тим різноманітніше — щоразу показуються 5 випадкових) і слово, що додається до пошуку («рецепт», «город», «здоров'я»; для «Історій» слово порожнє).
- **Збережені відео** — створення категорій (підтек), видалення, кнопка «Відкрити теку в закладках Chrome».
- **Ховати Shorts і коментарі** — увімкнено за замовчуванням.
- **Резервна копія** — збереження і завантаження налаштувань у JSON-файл.

## 8. Відомі обмеження
- **Facebook** — найкращі зусилля. Facebook часто змінює сторінки; розширення відкриває профіль і шукає «НАЖИВО». Якщо не знайшло — покаже підказку «Трансляція має бути вгорі сторінки. Натисніть на неї.» Потрібно, щоб бабуся була залогінена у Facebook.
- **Звук автозапуску** — Chrome може блокувати автоматичне відтворення зі звуком. Кнопка «Дивитися» (натискання Enter) допомагає: це дія користувача. Якщо відео стоїть без звуку чи на паузі, натисніть Пробіл.
- **Звук нагадування** може не лунати, доки на сторінці не було жодного натискання. Тому потрібен «дзвіночок» разом із великим екраном.
- **YouTube змінює вигляд сторінок** — підсвітка відео та екран «Що дивитися далі» можуть перестати працювати. Усі селектори зібрано у `src/content/yt-selectors.js`.
- Розклад працює, лише коли Chrome запущений і ноутбук не спить.
- Налаштування синхронізуються через акаунт Chrome (`chrome.storage.sync`, обмеження — близько 100 КБ; для розкладу — приблизно 20 записів).
- Якщо після відкриття нової вкладки стрілки не працюють — клацніть мишею по сторінці один раз. Зазвичай цього не потрібно: розширення саме повертає фокус зі адресного рядка на сторінку (головна сторінка відкривається ще раз з `?f=1`; це нормально).

## 9. Збережені відео, історія і бічна панель
- Кнопка **«⭐ Зберегти»** (жовта, внизу ліворуч на сторінці відео) кладе відео у закладки Chrome, у теку **«Бабусині відео»** (в «Інших закладках»). Підтеки цієї теки — категорії. Закладки живуть в акаунті Chrome і **переживають перевстановлення розширення**. Керувати ними можна й у менеджері закладок Chrome.
- Сторінка **«⭐ Мої відео»** (плитка на головній) показує «Продовжити перегляд» (історія, до 8 відео, з місця зупинки) і «Збережені».
- Історія зберігається локально (`chrome.storage.local`), до 30 відео.
- **Бічна панель**: клік по значку розширення. Щоб значок завжди був на видноті, натисніть значок «пазла» у Chrome і «закріпити» біля «Бабусин помічник».
- На сторінці відео стрілки ↓/↑ вибирають «Зберегти» і рекомендовані відео, Enter відкриває; решта клавіш YouTube працює як завжди.

## 10. Автоматичні оновлення
Ідея: онук публікує реліз на GitHub, а ноутбук бабусі сам завантажує файли в ту саму теку і перезавантажує розширення у безпечний момент (не ближче ніж за 15 хвилин до трансляції). Налаштування і дані зберігаються.

**Важливо: не переносьте і не перейменовуйте теку розширення** (наприклад `C:\Babusia\GrannyExtention`). Ідентифікатор розширення залежить від шляху: інакше Chrome вважатиме його новим, і налаштування та історія пропадуть. Не додавайте `key` у `manifest.json` з тієї ж причини.

### Одноразове налаштування (через Chrome Remote Desktop)
1. Переконайтесь, що розширення вже підключене з теки `C:\Babusia\GrannyExtention` (розділ 1).
2. Відкрийте PowerShell (звичайний, не від адміністратора) і вставте:
```
irm https://raw.githubusercontent.com/yyyaniv/granny-extension/main/windows/install.ps1 -OutFile $env:TEMP\i.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\i.ps1 -ZipUrl https://github.com/yyyaniv/granny-extension/releases/latest/download/BabusynPomichnyk.zip
```
3. Скрипт скопіює `update.ps1` в `%LOCALAPPDATA%\BabusynPomichnyk\`, створить завдання планувальника `BabusynPomichnyk-Update` (при вході в Windows і щогодини, без вікон), одразу перевірить оновлення і напише українською, чим закінчилось.
4. Параметри: `-ExtensionDir` (інша тека), `-CreateIfMissing` (завантажити розширення, якщо теки ще немає), `-UpdateScriptUrl`, `-Uninstall` (прибрати автооновлення; розширення лишається).

Репозиторій має бути публічним (або посилання доступні без входу), бо ноутбук завантажує файли без пароля.

### Як випустити нову версію (на Mac)
1. Підніміть версію в `manifest.json` і `package.json` (однакову).
2. `npm run release -- --publish` — запустить тести і перевірку, зробить `dist/BabusynPomichnyk.zip` і створить реліз (`gh`). Без `--publish` скрипт лише збере архів і покаже команду `gh release create`.
3. За годину (або після входу в Windows) ноутбук оновиться.

### Як перевірити на ноутбуці
- Журнал: `%LOCALAPPDATA%\BabusynPomichnyk\update.log` (рядки `[0] Оновлено до …`, коди помилок описані на початку `update.ps1`).
- `chrome://extensions` — версія розширення. Якщо вона не змінилась, а файли вже нові — розширення перезавантажиться само за кілька хвилин (або натисніть кнопку оновлення біля нього).
- Відкриті сторінки розширення після перезавантаження відновлюються; вкладки YouTube, що були відкриті, потрібно оновити (F5).

### Перед великими змінами
Збережіть налаштування у файл (Налаштування → «Резервна копія» → «Зберегти налаштування у файл»). Сама схема налаштувань оновлюється автоматично (наприклад, у версії 1.1.0 для незмінених тем додаються нові списки фраз і тема «Історії»; ваші власні теми не змінюються).
